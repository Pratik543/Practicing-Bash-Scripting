# Practicing-Bash-Scripting


## How to Download and Use

You can download and run the script with a few simple commands.

### 1. Download the Script

Use `curl` to download the script directly from this GitHub repository. The `-o` flag allows you to specify the output filename.

```
curl -o aws-resource-list.sh https://raw.githubusercontent.com/Pratik543/Practicing-Bash-Scripting/main/aws-resource-list.sh
```

### 2. Make the Script Executable

After downloading, you need to give the script execute permissions.

```
chmod 751 aws-resource-list.sh
```

### 3. Run the Script

Now you can execute the script:

```
./aws-resource-list.sh
```

or you can use any other script as per your choice.
